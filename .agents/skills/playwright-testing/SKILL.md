# Playwright Testing Skill

## Test Automation Scope
1. **Customer Happy Path**:
   - Registration with email verification flow.
   - User authentication and session persistence.
   - Catalog browsing, category filters, and live search.
   - Interactive 4-step custom pizza builder (Base -> Sauce -> Cheese -> Veggies).
   - Cart adjustments (increment, decrement, removal, total calculations).
   - Checkout flow and order placement with Razorpay integration mock/test verification.
   - Real-time order tracking timeline.
2. **Admin Operations**:
   - Dedicated admin login `/admin/login`.
   - Real-time inventory adjustments and low-stock threshold configuration.
   - Order management and live status transition triggers.
3. **Responsive Visual Testing**:
   - Capture full-page screenshots at 360px, 768px, 1024px, and 1440px viewports.
   - Verify zero horizontal scrolling and proper UI element stacking.
